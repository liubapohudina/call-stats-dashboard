# 📞 Call Stats Dashboard

A dark, neon-violet analytics dashboard for tracking customer call statistics — sentiment breakdown, daily call volume, and AI-generated insights, powered by an **n8n AI Agent** backend.

## ✨ Features

- **Real-time stats card** — total calls, positive/negative split, live-updating with a pulse indicator
- **Donut chart** — sentiment breakdown (positive vs. negative), built with MUI X Charts
- **Scatter chart** — daily call volume over time, point size mapped to negative call percentage
- **Date range picker** — query stats for any custom period (defaults to the last 7 days)
- **AI-generated recommendation** — a short, actionable insight generated by an LLM based on real call data
- **Glassmorphism criteria cards** — explains the methodology behind each call's evaluation
- **Floating chat button** — quick stats summary + direct link to discuss results in chat
- **Dark neon-violet theme** — custom design system built on CSS custom properties + MUI theming

## 🏗️ Architecture

```
┌─────────────┐      GET /webhook/get-call-stats     ┌──────────────────┐
│   Website   │ ────────────────────────────────────▶│   n8n Webhook    │
│  (React SPA)│    ?startDate=...&endDate=...         │     Trigger      │
└─────────────┘                                        └────────┬─────────┘
      ▲                                                          │
      │                    JSON (CallStats)                      ▼
      │                                                 ┌──────────────────┐
      └─────────────────────────────────────────────────┤     AI Agent     │
                                                          │  (LLM + Tool)    │
                                                          └──────────────────┘
```

The same n8n **AI Agent** serves two triggers:

- `When chat message received` — for conversational chat testing
- `Webhook` — for the live website, returning structured JSON matching the `CallStats` TypeScript interface

## 🚀 Getting Started

### Prerequisites

- Node.js 18+
- npm

### Installation

```bash
git clone https://github.com/your-username/call-stats-dashboard.git
cd call-stats-dashboard
npm install
```

### Environment

Update the n8n webhook URL in `src/api/stats.api.ts`:

```typescript
const N8N_WEBHOOK_URL =
  'https://your-n8n-instance.app.n8n.cloud/webhook/get-call-stats';
```

### Run locally

```bash
npm run dev
```

The app will be available at `http://localhost:5173`.

### Build for production

```bash
npm run build
```
